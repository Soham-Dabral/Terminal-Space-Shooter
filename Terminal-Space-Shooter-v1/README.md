# Terminal Space Shooter

A terminal-based space shooter game written in Python.

## Features
- Player movement
- Enemy spawning
- Bullet collision system
- Bomb shot every 4 bullets
- Score tracking
- Lives system

## Controls
- A → Move Left
- D → Move Right
- F → Fire Bullet
- Q → Quit Game

## Technologies Used
- Python
- Terminal Rendering
- Lists, Tuples, Sets, Dictionaries

## What I Learned
- Game loops
- State management
- Collision detection
- Debugging update-order bugs
- Structuring larger Python programs

## How to Run

Run:

```bash
python space_shooter.py
